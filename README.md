# protect-legal
Protect est un bot de sécurité tout-en-un pour Discord. Il protège ton serveur contre les raids, le spam et les nukes grâce à des systèmes de détection automatique, tout en offrant des outils de modération complets (ban, kick, mute, warn, purge) et un système de vérification par bouton pour filtrer les nouveaux membres. Par ailleurs gratuitement.
